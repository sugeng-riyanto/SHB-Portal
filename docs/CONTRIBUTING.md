# Kontribusi

Gunakan branch terpisah, perubahan kecil dan PR yang menyatakan masalah, solusi, migrasi, risiko dan hasil tes. Review akses, perhitungan uang dan dampak data oleh pihak berwenang. Hindari data nyata dan secrets dalam issue/PR. Update dokumentasi dan AI_HANDOFF bila ada perubahan penting. Branch protection dan kebijakan merge ditetapkan setelah repo tersedia.
